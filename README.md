## For installing it:
1. Clone 
2. Create Virtual env (python -m venv .venv)
3. Activate .venv:
    - Windows: .\.venv\Scripts\activate
    - Linux: source .venv/bin/activate
4. Install all necesary libruarys: (pip install -r requirements.txt)
5. python manage.py runserver
